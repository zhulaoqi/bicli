# 仪表盘指标采集 API 参考

## 完整指标采集清单

按顺序（尽量并行）调用以下 API 采集仪表盘数据。

### 用户板块

| 指标 | 工具 | 参数 |
|------|------|------|
| 用户总数 | data_aggregate | `{ "table": "users", "metric": "count" }` |
| 按状态分布 | data_aggregate | `{ "table": "users", "metric": "count", "groupBy": "status" }` |
| 按角色分布 | data_aggregate | `{ "table": "users", "metric": "count", "groupBy": "role_id" }` |

### 表单板块

| 指标 | 工具 | 参数 |
|------|------|------|
| 表单总数 | data_aggregate | `{ "table": "forms", "metric": "count" }` |
| 按状态分布 | data_aggregate | `{ "table": "forms", "metric": "count", "groupBy": "status" }` |

### 角色板块

| 指标 | 工具 | 参数 |
|------|------|------|
| 角色列表+权限 | role_list | `{}` |

### 配置板块

| 指标 | 工具 | 参数 |
|------|------|------|
| 全部配置项 | config_get | `{}` |

## 告警规则参考

| 指标 | 告警条件 | 级别 | 建议 |
|------|---------|:----:|------|
| inactive 占比 | > 50% | 🟡 | 清理停用账号 |
| admin 用户数 | > 3 | 🟡 | 审核是否过度授权 |
| admin 用户数 | = 0 | 🔴 | 系统无管理员，紧急修复 |
| draft 表单积压 | > 10 | 🟡 | 提醒创建者发布或清理 |
| published 表单 | = 0 | 🟡 | 系统无可用表单 |
| 配置项数 | = 0 | 🟡 | 可能未初始化 |
| 空权限角色 | 存在 | 🟡 | 孤立角色需清理 |

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 BiCLI 系统仪表盘
━━━━━━━━━━━━━━━━━━━━━━━━━━━

👥 用户  总数:N  活跃:X  停用:Y
   Admin:A  Editor:B  Viewer:C

📋 表单  总数:N  发布:X  草稿:Y  归档:Z

🔐 角色  N 个角色  M 项权限

⚙️ 配置  N 项

⚠️ 告警
🟡 [内容]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## role_id 到角色名映射

仪表盘显示角色名而非 ID。需先调用 `role_list` 获取 id→name 映射，再用于用户角色分布的展示。

# DataEye 可视化资源查询与分析 Skill

帮助用户查找 DataEye 可视化资源，执行真实数据查询，并给出数据洞察。

## 首选业务动作

用户要“查看/分析某个资源的真实数据”时，优先调用 `dataeye_dashboard_execute`，并传入用户原始名称或引用作为 `dashboardRef`。不要自己把名称猜成 ID，不要把 `folderId` 当作执行 ID，也不要把资源 ID 当作 `viewId` 传给 `dataeye_chart_data_execute`；单图/视图工具只用于用户明确要求执行某个单独组件。

## 工作流程

### 场景一：用户问"有哪些资源"

**直接调用，不要先说话：**

```
步骤1: dataeye_dashboard_list(orgId=<当前orgId>)
   → 获取资源列表。返回中的 id 是可执行 relId，folderId 只是目录节点 ID

步骤2: 整理并展示看板列表
```

**输出格式：**
```
找到 N 个资源：

📊 [资源名称A]  ID: xxx  更新: 2026-04-01
📊 [资源名称B]  ID: xxx  更新: 2026-03-28
...

输入资源名称或 ID 可查看详情和数据。
```

### 场景二：用户说"帮我看下[资源名称]的数据"

```
步骤1: dataeye_dashboard_execute(dashboardRef=<用户原始名称或引用>)
   → 工具自动解析真实 relId、获取结构并逐个执行资源中的图表和视图组件

步骤2: 汇总解读，输出结论
```

### 场景三：用户说"分析这个资源的结果"

在获取数据后，按图表类型给出有意义的解读：

**折线图/柱状图（趋势类）：**
- 说出指标的数值范围和近期趋势（上升/下降/波动）
- 找出最高点和最低点及对应时间
- 与上期横向对比（如有）

**饼图/占比图：**
- 说出占比最大的 Top 3 类别
- 指出异常占比（如单一类别超过 50%）

**数值卡片（KPI）：**
- 直接读出数值
- 如有同比/环比字段，给出增减百分比

**表格数据：**
- 提炼关键行（最大值/最小值行）
- 不要逐行读出，只展示摘要

## 输出结果格式

```
📊 资源：[资源名称]

━━ [图表1名称] ━━
数据摘要：...
洞察：...

━━ [图表2名称] ━━
数据摘要：...
洞察：...

📝 综合结论：[1-2句总结]
```

## 错误处理

| 情况 | 处理 |
|------|------|
| 资源列表为空 | "当前组织下暂无可见资源" |
| 找不到指定名称 | 列出名称相似的看板供选择 |
| 图表数据为空 | "该图表暂无数据；只能说明当前查询条件下无返回数据，不要推断根因" |
| 执行超时 | "数据量较大，建议缩短时间范围后重试" |
| 权限不足 | "您没有该看板的访问权限" |

## 注意事项

- **不要输出原始 JSON**：只展示经过整理的摘要和洞察
- **图表数量多时**：优先展示用户关注的图表，其余提示"还有 N 个图表，是否继续查看？"
- **数据敏感字段**：不要在回复中展示完整的数据行，只展示统计摘要
- **ID 使用规则**：`dataeye_dashboard_list` 返回的 `id` 才是可执行 ID；`folderId` 不可用于执行。用户提供名称时直接传 `dashboardRef`，让工具解析。
- 详细 API 参数见 [reference/api.md](reference/api.md)

# DataEye 数据看板查询与分析 Skill

帮助用户查找 DataEye 数据看板，执行看板真实数据查询，并给出数据洞察。

## 首选业务动作

用户要“查看/分析看板真实数据”时，优先调用 `dataeye_dashboard_execute`。不要把看板 ID 当作 `viewId` 传给 `dataeye_chart_data_execute`；单图表工具只用于用户明确要求执行某个高级图表。

## 工作流程

### 场景一：用户问"有哪些看板"

**直接调用，不要先说话：**

```
步骤1: dataeye_dashboard_list(orgId=<当前orgId>)
   → 获取看板目录树，提取所有 vizType=DASHBOARD 的条目

步骤2: 整理并展示看板列表
```

**输出格式：**
```
找到 N 个看板：

📊 [看板名称A]  ID: xxx  更新: 2026-04-01
📊 [看板名称B]  ID: xxx  更新: 2026-03-28
...

输入看板名称或 ID 可查看详情和数据。
```

### 场景二：用户说"帮我看下[看板名称]的数据"

```
步骤1: dataeye_dashboard_list() → 找到目标看板 ID

步骤2: dataeye_dashboard_execute(dashboardId=<id>)
   → 自动获取看板结构并逐个执行看板中的图表

步骤3: 汇总解读，输出结论
```

### 场景三：用户说"分析这个看板的结果"

在获取数据后，按图表类型给出有意义的解读：

**折线图/柱状图（趋势类）：**
- 说出指标的数值范围和近期趋势（上升/下降/波动）
- 找出最高点和最低点及对应时间
- 与上期横向对比（如有）

**饼图/占比图：**
- 说出占比最大的 Top 3 类别
- 指出异常占比（如单一类别超过 50%）

**数值卡片（KPI）：**
- 直接读出数值
- 如有同比/环比字段，给出增减百分比

**表格数据：**
- 提炼关键行（最大值/最小值行）
- 不要逐行读出，只展示摘要

## 输出结果格式

```
📊 看板：[看板名称]

━━ [图表1名称] ━━
数据摘要：...
洞察：...

━━ [图表2名称] ━━
数据摘要：...
洞察：...

📝 综合结论：[1-2句总结]
```

## 错误处理

| 情况 | 处理 |
|------|------|
| 看板列表为空 | "当前组织下暂无看板，请先创建数据看板" |
| 找不到指定名称 | 列出名称相似的看板供选择 |
| 图表数据为空 | "该图表暂无数据，可能是时间范围或数据源问题" |
| 执行超时 | "数据量较大，建议缩短时间范围后重试" |
| 权限不足 | "您没有该看板的访问权限" |

## 注意事项

- **不要输出原始 JSON**：只展示经过整理的摘要和洞察
- **图表数量多时**：优先展示用户关注的图表，其余提示"还有 N 个图表，是否继续查看？"
- **数据敏感字段**：不要在回复中展示完整的数据行，只展示统计摘要
- 详细 API 参数见 [reference/api.md](reference/api.md)

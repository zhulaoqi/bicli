# DataEye 买量监控帮助

买量监控是数眼中用于观察投放、变现和转化表现的监控看板能力。用户通常用它查看广告投放相关指标、定位渠道或广告层级的效果波动，并结合数据更新时间、时区、币种和维度说明理解报表口径。

## 可以回答

- 买量监控能做什么：查看买量相关的数据表现与指标口径，辅助判断投放效果。
- 数据更新时间：看板数据不是实时秒级刷新，分析时要关注页面展示的数据更新时间。
- 时区与币种：跨地区或跨平台对比时，需要确认报表使用的时区和币种口径，避免误判。
- 维度：可围绕投放、渠道、广告、地区等维度查看效果；具体可用维度以产品页面为准。
- ROAS：通常用于衡量广告投入产出，可理解为广告带来的收入与广告花费的比值。
- ROI：通常用于衡量整体投资回报，具体口径可能受业务配置影响。
- ROSE：不要当作 DataEye 官方指标解释。优先说明“可能是 ROAS 的误写”，并请用户确认。

## 不能回答成数据

- “用户列表有多少用户”“某个买量看板现在有多少条数据”“今天 ROAS 是多少”属于实时数据问题，必须调用实际数据或看板工具。
- 如果工具返回空，只能说没有查到对应数据，不能编造典型指标、用户数、广告数或看板结果。

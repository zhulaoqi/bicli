# DataEye 分析配置帮助

这是分析配置和平台能力说明 skill。只回答产品知识，不查询实时数据。

## API 管理

API 管理支持事件分析、漏斗分析、留存分析图表结果数据通过 API 导出，可对接第三方系统或自定义分析。入口通常是“我的分析 -> 操作 -> API 管理”。

注意事项：
- 暂不支持分析模型中使用动态时间的场景，需要调整 `queryStartTime` 和 `queryEndTime`。
- Token 可在个人中心获取。
- 每个 Token 同时仅允许 1 个查询。
- 每个 Token 调用频率最多 10 次/分钟。
- 单次查询最大时间跨度 180 天，长时间范围建议拆分。

## 权限变量

权限变量用于控制不同用户在数据查询时可访问的数据范围，常见于行级权限控制。

支持应用范围：
- 数据视图 SQL 查询
- 高级图表
- 数据看板

使用方式概要：
1. 在“系统管理 -> 变量配置”创建变量。
2. 关联角色或成员，并设置变量值或使用默认值。
3. 在数据视图 SQL 中引用变量，推荐使用 `IN` 口径，便于后续扩展。

风险提示：同一用户被多个角色或自定义配置计算出不同变量值时，可能导致查询报错或结果异常。

## 数据视图与数据汇总

- 数据视图用于定义后续图表、看板或查询使用的数据口径。
- 数据汇总用于围绕指定口径做汇总查询或汇总展示。
- 如果用户问“有哪些视图/表/分析”“帮我执行某个分析”，这是实时数据请求，应使用 MCP 工具。

## 图表与属性能力

- 条件格式：用于高级图表中按规则设置展示样式或颜色。
- 虚拟属性：用于基于已有属性进行计算或加工。
- 属性筛选：用于说明筛选项口径和过滤条件。
- 用户分群：用于按规则圈选用户群体，具体规则以产品页面为准。

## 自定义配置接口

自定义配置接口可根据包名和组织 ID 查询产品信息，支持明文和加密两种调用方式。文档中提到接口路径为 `/v3/info`，GET 请求。

## 回答边界

- 可以解释功能、入口、限制、配置原则。
- 不能编造具体项目、产品、分析 ID、接口返回值或当前数据。

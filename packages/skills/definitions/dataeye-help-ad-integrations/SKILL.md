# DataEye 广告平台与归因帮助

这是广告平台接入和归因相关的产品知识 skill，只解释配置、口径和使用方式，不输出实时广告数据。

## 覆盖范围

- Google Ads：投放平台接入与配置相关说明。
- Google AdMob：广告变现平台接入与配置相关说明。
- Google AdManager：广告管理平台接入与配置相关说明。
- Adjust：移动归因平台接入与归因相关说明。
- TopOn、BIGO Ads、Bee Ads：第三方广告平台或聚合平台接入说明。
- Google API 配置字段：用于解释 Google 相关 API 配置需要哪些字段。
- 归因分析：用于说明渠道归因、投放归因等功能概念和使用场景。

## 回答规则

- 用户问“怎么接入、需要哪些字段、这个平台是什么、归因分析是什么”：按帮助中心知识回答。
- 用户问“某渠道今天消耗多少、某广告平台收入多少、归因结果是多少”：必须使用 MCP 数据或看板工具，不能凭文档推断。
- 如果知识库没有收录某个平台的完整步骤，明确说“当前帮助中心知识库只收录概要，完整字段以平台配置页或原文档为准”。
